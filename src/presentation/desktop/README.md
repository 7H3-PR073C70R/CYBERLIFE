# Virtual Desktop Environment (`src/presentation/desktop/`)
Contains the in-game operating system interface: window manager (drag, resize, minimize, maximize, z-index focus), taskbar, application launcher, and virtual apps:
- `TerminalApp`: Synthetic command prompt.
- `SiemViewerApp`: Interactive log inspection & search.
- `EvidenceLockerApp`: Preserved evidence hashes & notes.
- `ReportAuthoringApp`: Incident report submission form.
- `MailApp`: In-game email client.
