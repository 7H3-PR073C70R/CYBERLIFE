# Design System & Styling (`src/styles/`)

Contains global CSS stylesheets, CSS custom properties (design tokens), font imports, and typography definitions for the Cyberlife interface.

## Guidelines
- Premium, dark-mode desktop terminal aesthetic.
- Monospace font stack for terminal and log viewers (`JetBrains Mono`, `Fira Code`, or `Courier New`).
- Accessible color contrast conforming to WCAG 2.1 AA standards.
- Reusable CSS variables for glassmorphism panels, window borders, and status colors.
